# Pro Podium Events & Hospitality

Institutional website for Pro Podium Events & Hospitality: Home, About, Services, Events (five category pages), Partners and Contact.

Static HTML and CSS, no build step needed to host it. Upload the files at the root of this repository to any static host.

- Test link: https://propodium-web-production.up.railway.app/
- `source/` holds the generator script (`build.py`), the page copy (`content.py`) and the stylesheet used to build the pages.
- `INSTALAR.md` has the install guide in Portuguese.

Site contact: info@propodiumevents.com, (737) 202-7261. Approved reviews go in the `REVIEWS` list in `source/content.py`.
