# ProPodium Events & Hospitality

Institutional website for ProPodium Events & Hospitality: Home, About, Partners and Contact.

Static HTML and CSS, no build step needed to host it. Upload the files at the root of this repository to any static host.

- Test link: https://propodium-web-production.up.railway.app/
- `source/` holds the generator script and stylesheet used to build the pages.
- `INSTALAR.md` has the install guide in Portuguese.

The contact email and phone are still placeholders (`EMAIL_AQUI`, `TELEFONE_AQUI`).
